How does brute-force cracking actually work?

A brute-force attacker tries every possible combination of characters, shortest first, until one matches. The number of guesses needed depends on the size of the character set and the length of the password — combinations grow exponentially, not linearly.

  • A 4-character lowercase-only password: ~475,000 possible combinations.
  • An 8-character password mixing upper/lower/digits/symbols: well over 6 quadrillion.
  • Real attackers also use dictionaries, leaked password lists, and pattern rules — brute force is usually a last resort, used only against short or unusual strings.
  • Length beats complexity: a long random passphrase is far harder to crack than a short "complex-looking" password.
